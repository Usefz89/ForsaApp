# Forsa - Sharia-Compliant Investment Platform MVP

A comprehensive MVP for a Trading 212-style halal investment platform targeting the GCC market, built for the Motawer competition in Kuwait.

## 🎯 Project Overview

**Platform Name**: Forsa (Arabic for "Opportunity")
**Target Market**: GCC (starting with Kuwait)
**Competition**: Motawer - Kuwait's largest fintech innovation event
**Funding Goal**: 60,000 KD from Motawer incubator
**Timeline**: 1-week MVP development

## ✨ Core Features Implemented

### 1. **Landing Page**
- Beautiful gradient design with bright, inviting colors
- Hero section highlighting Sharia compliance
- Feature showcase with 6 key value propositions
- Statistics section and compelling CTAs
- Professional footer with regulatory mentions

### 2. **User Authentication**
- Clean sign-up/sign-in flow
- Email and password authentication
- Responsive design with Forsa branding
- Demo account creation for MVP

### 3. **Portfolio Dashboard**
- Real-time portfolio overview with performance metrics
- "Quick Actions" section for easy navigation
- Personal portfolio cards with detailed holdings
- Recent activity feed
- Professional navigation with user avatar

### 4. **Stock/ETF Browser**
- Tabbed interface for Stocks vs ETFs
- Advanced search and filtering
- Sharia compliance indicators (Shield icons)
- Real-time price data display
- Market information including Kuwait Stock Exchange
- "Add to Pie" functionality

### 5. **Community Features**
- Public portfolio discovery
- Copy trading functionality
- Creator profiles and follower system
- Performance-based filtering (trending, best performance)
- Social engagement (likes, comments)
- Featured creators section

### 6. **Zakat Calculator**
- Comprehensive Islamic tax calculator
- Multiple asset categories (investments, cash, gold, silver, business)
- Debt deduction capabilities
- Nisab threshold checking
- Educational content about Zakat
- Real-time calculation updates

## 🎨 Design System

### Color Palette
- **Primary Purple**: Modern, trustworthy purple gradients
- **Secondary Green**: Representing halal/growth
- **Accent Blue**: Technology and innovation
- **Background**: Clean whites with subtle gradients

### Typography
- **Font**: Inter (clean, modern sans-serif)
- **Hierarchy**: Clear heading and body text styles
- **Accessibility**: High contrast ratios

### UI Components
- Custom Tailwind CSS configuration
- Shadcn/ui component library
- Consistent spacing and border radius
- Forsa-branded gradients and shadows

## 🛠 Technical Architecture

### Frontend Stack
- **Framework**: Next.js 15 with TypeScript
- **Styling**: Tailwind CSS with custom theme
- **Components**: Shadcn/ui component library
- **Icons**: Lucide React
- **State Management**: React hooks (expandable to Zustand)

### Backend (Configured)
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **API**: Next.js API routes

### Deployment Ready
- **Hosting**: Vercel (optimized for Next.js)
- **Environment**: Production-ready configuration
- **Domain**: Ready for custom domain setup

2. Add Supabase credentials (optional for MVP)
3. Run development server
